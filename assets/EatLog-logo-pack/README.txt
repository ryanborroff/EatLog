EATLOG LOGO PACK

Selected direction
Option 07: bold EatLog wordmark with the 'o' replaced by a three-bar voice mark.

Files
- eatlog-primary-black.svg / .png — primary logo
- eatlog-reversed-white.svg / .png — reversed logo
- eatlog-green.svg / .png — green treatment
- eatlog-mark.svg — standalone circular voice mark
- eatlog-app-icon-1024.png — light app icon
- eatlog-app-icon-dark-1024.png — dark app icon

Construction
Typeface recreation: Inter Display Bold.
The generated concept artwork did not correspond to a dependable commercial font, so this pack recreates the selected design using a real typeface and custom vector geometry.

Colour
Black: #000000
White: #FFFFFF
EatLog green: #16A36A
Off-white icon background: #F7F6F2
Dark icon background: #0A1211

Usage
Use the black wordmark on light backgrounds and the white wordmark on dark backgrounds.
The standalone mark can be used for the app icon, voice/listening controls and compact brand applications.
SVG files remain editable and scalable. PNG wordmarks have transparent backgrounds.
